How do I add a PS2 game step by step?

  1. Connect the drive to your phone with a USB OTG adapter and open Ultimate USB or USB Tools.
  2. Open the Gaming Tools group and tap PS2 USB Utils.
  3. At the top, check File System:, Partition Table: and Available Space:. If the drive is not FAT32 or exFAT with an MBR partition table, tap Fix first.
  4. Tap Import & Split ISO and pick an ISO or ZSO game file.
  5. Choose the Installation Method when the app asks, and start the copy.
  6. The game appears in the list. The app shows Found N game(s), or No Games Found when the drive has none.

The list shows the games in ul.cfg, the PS2 ISO games in /CD and /DVD, and the PS1 games in /POPS.

How do I prepare the drive for OPL with Fix?

Fix is available when the drive is not FAT32 or exFAT, or when its partition table is not MBR. What it does depends on the drive:

  • If the file system is not FAT32 or exFAT, the drive does not have exactly one partition, or the partition is larger than MBR allows, the app formats the drive. Choose FAT32 or exFAT; the label is PS2 unless you change it. The app shows All Data Will Be Permanently Deleted and the token cost before it starts. The drive gets an MBR partition table, and the partition is limited to the MBR maximum size.
  • If the drive already has one FAT32 or exFAT partition that fits, the app only rewrites the partition table as MBR. It does not format, your files stay on the drive, and it uses no token.

Fix stays off when another volume on the drive was not closed properly.

Should I use Direct Copy or split the game to UL?

Use Direct Copy - Recommended when the app offers it. The choice appears when the game file is smaller than 4 GB, or when the drive is exFAT. A game of 4 GB or more on a drive that is not exFAT is always split into USBExtreme (.ul) parts, and ul.cfg is updated.

CSO files are refused with Unsupported File. Convert them to ISO or ZSO first with Game Converter. If an image is not complete, the app says This image is incomplete. Download it again.

How do I import a game that is already in .ul format?

Tap Import .ul game and pick the folder. If the folder holds ul.* parts or a ul.cfg, the app imports the UL game. Otherwise it offers the .iso and .zso files in that folder.

How do I add PS1 games for POPStarter?

Tap Import VCD Game and pick a .VCD file. Only .VCD files are accepted. The app then shows Copying image…, Writing launcher… and Updating conf_apps.cfg…. It creates the launcher /POPS/XX.<name>.ELF.

  • The name may use letters, numbers, spaces, dots, hyphens and underscores. The launcher path can be up to 89 characters.
  • A game with the same name already in /POPS is refused.
  • On FAT32, a .VCD file of 4 GB or more is refused. The app also checks that there is enough free space.
  • The app warns you when the drive uses GPT.

POPStarter needs a system file (POPS_IOX.PAK) that the app does not include; you supply it yourself. While it is missing, the app shows Setup incomplete. Tap the banner, and in One step remains tap Select file to add it.

On a write-protected (read-only) drive, the app refuses every action that writes to the drive.

After Rename or Delete, the app tells you what the drive did. If a job stops at a bad sector, the app offers Check the drive.

How do I download game covers?

Tap Download Game Arts and choose What to download: Artwork and game info or Artwork only. This needs an internet connection. A game with an unusual or renamed game ID may have no artwork to match.

With Artwork and game info, the game info is saved in CFG/<ID>.cfg, where <ID> is the game ID. A CFG file that is already on the drive is never replaced.

Is PS2 USB Utils safe for my drive?

Yes. The app tests every format before it reports success, and it protects the drive at each step:

  • When Fix formats the drive, it checks and tests the new file system before the app reports success.
  • If the drive did not keep its test data, it may be fake. The app says so, keeps its files read-only and offers Try restore again. Fix still formats the drive after an extra Yes; if you answer No, the token comes back.
  • If you kept the claimed size of a drive that may be fake, the app warns you once before it writes, with Continue and Cancel. If you cancel, nothing is written and no token is used.
  • A job never writes to a different drive than the one it started on.
  • If the USB connection fails for a moment during a job, the app recovers it automatically and the job continues.

Does PS2 USB Utils use tokens?

Only Fix uses a token, and only when it formats the drive: 1 token. The app shows the cost before it starts, and you earn a token by watching one short rewarded video. Adding, exporting, renaming, deleting games and downloading covers use no tokens. With Pro, Fix uses no tokens.

The token comes back when the drive is gone after you confirm, when you decline the prompt to overwrite the whole drive, when the format fails or stops with an error, and when the job is cancelled or the app is closed (it is returned the next time the app starts).

Does the app include PS2 or PS1 games?

No. The app organises game files you already own. It does not include game images, BIOS files or console firmware.
