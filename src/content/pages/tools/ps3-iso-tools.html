How do I use PS3 ISO TOOLS step by step?

  1. Open Ultimate USB or USB Tools.
  2. Open the Gaming Tools group and tap PS3 ISO TOOLS.
  3. Tap the action you need: Split ISO, Split PKG, Join ISO, Join PKG, Extract ISO, Make ISO, Modify ISO, Patch ISO or Info ISO.
  4. Pick the source file or folder, set the options, and pick where the result goes.

How do I split a PS3 ISO or PKG for a FAT32 drive?

Tap Split ISO or Split PKG, pick the .iso or .pkg file, choose the Split options, then pick the output folder.

OptionValuesDefault
Part size1 GB, 2 GB, 3 GB, or Custom… with Size in MB (16 MB to 3 GB)3 GB
Place parts in a folder named after the fileOn, offOn

PKG parts are named .66600, .66601 and so on. If the file is smaller than the part size, the app tells you. If you cancel, the parts that are already finished are kept.

How do I join split parts back into one file?

Tap Join ISO or Join PKG, pick the folder of the split set and its first part. If a part is missing, the app tells you the set is incomplete.

How do I extract a PS3 ISO?

Tap Extract ISO and pick the ISO. Tick Split files over 4 GB into parts (for FAT32 drives) if the files go to a FAT32 drive; it is off by default. Split files get the endings .666NN.

How do I make an ISO from a game folder?

Tap Make ISO and pick the game folder. The folder must contain PS3_GAME/PARAM.SFO and can have up to 4096 folders. Tick Split into 4 GB parts (for FAT32 drives) if you need parts; it is off by default.

How do I rename an ISO or add tags?

Tap Modify ISO and choose one or more of the ISO-Modify-Options. All are off by default; if you choose none, the app tells you.

  • Rename: [Game-Name] [ID]
  • Add [auto] tag
  • Add [online] tag
  • Extract Icon & SFO

How do I patch an ISO for my CFW version?

Tap Patch ISO, pick the ISO, and set the Target CFW version. The default is 4.76. The app accepts versions from 4.21 up to, but not including, 4.90.

How do I see the game details of an ISO?

Tap Info ISO and pick the ISO. The app shows Title, Title ID, Version, App Version, Category, Parental Level, Required Firmware and Resolution.

Does PS3 ISO TOOLS use tokens?

No. Every action in PS3 ISO TOOLS is free.
