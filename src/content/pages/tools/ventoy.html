How do I install Ventoy step by step?

  1. Connect the drive to your phone with a USB OTG adapter. Open Ventoy (Unofficial), or in Ultimate USB open the Bootable & Image Writing group and tap Ventoy - Unofficial.
  2. Ventoy In Package: shows the Ventoy version the app will install. Ventoy In Device: shows the version already on the drive, and stays empty when there is none.
  3. *Partition Table: choose MBR or GPT.
  4. *File System: choose FAT32, EXFAT or NTFS.
  5. *Cluster Size: keep the size the app selects, or pick another one from the list.
  6. Tick or untick Secure Boot Support and *Align partitions with 4K.
  7. Tap Install. The app shows The disk will be formatted and all data will be lost. and how many tokens the install uses. Tap OK to start.
  8. Wait until the install finishes. The message then says Next: copy your ISO files to the drive.

Options marked with an asterisk (*) are used only by the install. When Ventoy is already on the drive, the screen shows that drive's partition table, file system, Secure Boot and alignment settings. After an install, the app confirms the Ventoy version on the drive.

Ventoy is built into the app and ready to install, and you can choose another Ventoy version (see below). Ventoy (Unofficial) is an independent app, not affiliated with the Ventoy project.

Ventoy needs a drive with 512-byte sectors. On a drive with 4096-byte sectors (4K native), the app says that Ventoy cannot be installed on this drive, and nothing is installed.

Is installing Ventoy safe for my drive?

Yes. The app tests every Ventoy install before it reports success, and it protects the drive at each step:

  • The app checks the drive when you connect it. If the drive may be fake or faulty, it shows 🛑 CRITICAL WARNING: BAD DRIVE! and offers to scan for the size the drive really has.
  • If the drive did not keep its test data, it may be fake. The app says so, keeps its files read-only and offers Try restore again. Install still runs after an extra Yes; if you answer No, the tokens come back.
  • A drive that is write-protected or does not take writes is recognised as soon as you start a job: one clear message, and nothing is charged.
  • Install checks and tests the new file system before the app reports success.
  • A job never writes to a different drive than the one it started on.
  • If the USB connection fails for a moment during a job, the app recovers it automatically and the job continues.

Can I install Ventoy with GPT, or only MBR?

Both. Choose MBR or GPT under *Partition Table: before you tap Install. Drives larger than 2 TB always use GPT.

To switch a Ventoy drive to the other partition table, install again. Install erases the whole drive, including the ISO files on it, so copy them back afterwards. Update keeps your ISO files but does not change the partition table.

How do I update Ventoy without losing my ISO files?

Connect the Ventoy drive and tap Update. The app shows Upgrade operation is safe, ISO files will be unchanged. and how many tokens the update uses. Tap OK.

Update does not format the drive and keeps its partition table. If Ventoy is not on the drive, the app shows Ventoy is not installed on this USB device. Please install it first. with the buttons Install and Close.

How do I remove Ventoy from a drive?

Tap Clear. The app shows The disk will be formatted and all data will be lost. and how many tokens it uses. Tap OK. Clear removes Ventoy and formats the drive, so the ISO files on it are deleted too.

How do I use another Ventoy version?

Tap the version next to Ventoy In Package: and choose it in the Ventoy version sheet. By default the app uses its built-in version.

  1. The sheet lists the built-in version, each version you downloaded before with On this phone and its size, and Other version…. The version in use is marked Selected.
  2. Tap Other version…. The app loads the list of Ventoy releases from GitHub. Each row shows Download with the size, or On this phone when you already have that version.
  3. Tap a version. The app asks Download Ventoy … from GitHub? Confirm, and the app shows Checking Ventoy … while it checks the version.
  4. Tap Install or Update. Both use the version you chose.

If the list does not load, the app shows Could not load the list. Try again later. If the chosen version cannot be used, the app shows This Ventoy version could not be used. Nothing was written to the drive. and the tokens come back. To remove a downloaded version from the phone, tap Delete next to it and confirm.

The app does not show a notice when a new Ventoy version comes out. Open Other version… to see the releases.

How do I copy ISO files onto a Ventoy drive?

Tap Copy File To USB and choose the file in the system file picker. The app copies it to the Ventoy drive. Copying uses no tokens.

  • Ventoy boots the ISO, WIM, IMG, VHD and EFI files on the drive. To add more, just copy them; you do not reformat or reburn the drive.
  • If the drive does not have enough free space for the file, the app shows Not Enough Space.
  • If a file with the same name is already on the drive, the app asks File already exists. Replace it?
  • If you cancel a copy, the app asks Are you sure you want to cancel the process?
  • FAT32 limits single files to 4 GB, and an ISO is copied as one file. For larger ISOs, use exFAT or NTFS.
  • Copying the ISO files from a PC works too.

To delete or rename files on the drive, tap USB File Manager. An ISO you delete leaves the boot menu. Copy File To USB, the download button and USB File Manager work only when Ventoy is on the drive.

In USB File Manager you can pick several files at once. If a file cannot be read during an import, the app skips it and copies the rest.

USB File Manager can also open a file from the drive in another app without copying it first.

Can I download ISO files straight to the drive?

Yes. Tap Download File Directly To USB FROM INTERNET. The app opens its own browser, and the file you download is written to the Ventoy drive, with the same free-space check and replace question as a copy. Downloading uses no tokens.

How do I choose which ISO boots at startup?

Start the PC from the USB drive, then pick the system you want from the Ventoy menu.

  • Open the PC's boot menu at power-on (usually F12, F11, F9 or Esc) and select the USB drive.
  • Config Hub can set a Menu timeout and a Default boot entry.
  • If the phone does not recognise the drive after setup, it is probably working: test it on a PC.

How do I keep my changes in a live Linux (persistence)?

Use Add persistence on the Persistence tab of Config Hub. The app creates an ext4 image file on the drive and links it to the ISO you choose. This uses no tokens.

  1. Open Config Hub, then the Persistence tab, and tap Add persistence.
  2. Step 1 of 3 · Choose the ISO: pick the Linux ISO.
  3. Step 2 of 3 · Label and size: check the label and choose the size.
  4. Step 3 of 3 · Confirm: tap Create. The app shows Reserving space on the drive… and then Formatting the image…

The image file is named persist_ followed by the label and the size. Persistence works with the Ubuntu, Debian, MX and Arch families; openSUSE and most other systems do not support it through Ventoy.

What can I change with Config Hub and Theme Manager?

Config Hub changes Ventoy's settings on the drive (its ventoy.json file) without a computer. It has the tabs Boot, Names, Tips, Security and Persistence. After you save, the app shows Saved. Takes effect on next boot.

On the Boot tab you set, for example, Menu timeout (0 to 3600 seconds), Default menu mode (List or TreeView), Menu language, Keyboard layout, the file types to hide from the menu, Windows 11: bypass hardware checks and Windows 11: bypass online account. Settings in ventoy.json that the app does not show are kept.

Config Hub can also rename boot-menu entries, set a boot password and passwords for each file type, and set the tips text, its position and its color. It can repair a damaged ventoy.json file, with a backup.

Theme Manager changes how the Ventoy boot menu looks, with GRUB2 themes. Download a GRUB2 theme archive (zip, tar.gz or tar.xz), come back to Theme Manager, tap Import Theme and select the file. If the archive holds several themes, the app asks you to choose one. Use default goes back to the default theme.

In Theme Manager you can also apply, rename or delete a theme, and set the menu resolution.

Config Hub and Theme Manager work only when Ventoy is on the drive, and they use no tokens.

The app shows the cost before it starts, and you earn a token by watching one short rewarded video. With Pro, Ventoy uses no tokens. If you do not have enough tokens, the app shows Not Enough Tokens with a Get Tokens button, and nothing starts.

The tokens come back automatically when an install, update or clear fails, when an install or clear ends before anything is written, when the chosen Ventoy version cannot be used, and when the app is closed during the job (they are returned the next time the app starts).

What happens if the install is interrupted?

Install, Update and Clear have no Cancel button, so let them finish. Keep the app in front: when it goes to the background, the job pauses, and it continues when you come back to the app. The app keeps the screen on while it is shown.

In the free version, a running job also pauses while the phone has no internet connection or an ad blocker or blocking Private DNS is active, and continues when that is fixed. With Pro, only the background pause applies.

If the drive is removed or stops answering, the job ends and the app shows The drive was removed or stopped answering. Reconnect it and try again. The tokens come back. Reconnect the drive and run the job again.

Each failure has its own message, so you know what went wrong.
