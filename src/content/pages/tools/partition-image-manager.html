How do I create a new partition image?

  1. Open Ultimate USB, open the File & Storage group and tap Partition Image Manager.
  2. Tap Create Partition Image .img.
  3. Enter the name, the size and its unit (MB or GB), and a volume label, and choose the file system.
  4. Pick the folder where the image file is saved. The app checks that there is enough free space and whether a file with that name already exists.
  5. The app shows Your partition is ready! Would you like to open it? Open it to add files.

OptionValuesDefault

File systemFAT32, exFAT, NTFS, Ext2, Ext3, Ext4 (FAT16 is not offered)FAT32

How do I open an image file and see what is inside?

  1. In Partition Image Manager, tap View Partition Image (.img/.bk).
  2. Pick the image file, then pick a partition in it.
  3. Browse it as you would a drive in USB File Manager: Copy, Cut, Paste, Delete, Rename, Import, Export, Search and Sort.

This also opens a .bk backup made with Backup / Restore, so you can look inside it without restoring it to a drive.

Does Partition Image Manager use tokens?

No. Partition Image Manager is free.

To write an image file to a drive, use Raw Write.
