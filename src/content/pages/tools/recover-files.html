Steps

  1. Connect the drive to your phone with a USB OTG adapter and open Ultimate USB or USB Tools.
  2. Open the Data Recovery group and tap Recover deleted files.
  3. Optional: open Advanced options (see below).
  4. Tap Start scan. The app shows how much it has read and about how much time is left.
  5. Look through the results. Tap a file to preview it.
  6. Tick the files you want (or Select all). Tap Change folder if you want another folder on the phone.
  7. Tap Recover, then Save. When it is done, the app shows Files saved; tap Open folder to see them.

The scan only reads the drive. Nothing is written to it while it is scanned.

Which scan does the app run?

One scan, the Smart scan. There is no scan mode to choose. Some results are marked Found by content. Older saved scans may still show the names Quick scan, Deep scan (recommended) or Raw scan.

Advanced options

OptionWhat it does
Check every file found completely (slower, more reliable status)Checks each file it finds in full, so the status of each file is more reliable. The scan takes longer.
Copy the whole drive to the phone first (for drives with read errors)Copies the drive to the phone, then scans the copy. The phone needs enough free space for it. If you stop the copy, it is deleted from the phone.

Which drives and file types can it recover?

It reads FAT12, FAT16, FAT32, exFAT, NTFS, ext2, ext3 and ext4. It can find 201 file types, for example:

  • Photos: JPG, PNG, HEIC, PSD and camera RAW files such as CR2, CR3, NEF, ARW and DNG.
  • Videos: MP4, MOV, AVI, MKV.
  • Music: MP3, FLAC, WAV.
  • Documents: PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX.
  • Archives and other files: ZIP, RAR, 7Z, ISO, APK, SQLite.

The results are sorted into tabs: All files, Photos, Videos, Music, Documents, Archives and Other.

How do I find the right files in the results?

  • Switch between By type and By folder, or use Search by name.
  • Sort by Chance of recovery (best first), Name, Size (largest first) or Date (newest first), and use Filter to narrow the list.
  • Each file has a label: Checked: opens, Good chance, May be damaged, Overwritten or Unknown.

Can I preview a file before I recover it?

Yes. Tap a file to open its preview. Pictures and text are shown, including camera RAW, TIFF and Photoshop files, and AVCHD video. For an archive the app shows how many items it holds. A file type without a preview shows No preview for this type of file.

In the preview you can tap Check file, Open in another app or Recover this file.

Where are recovered files saved?

In the phone's Downloads folder, in Ultimate USB Recovery (or USB TOOLS Recovery in USB Tools), in a new folder named by the date and time.

Change folder picks another folder on the phone. A USB drive or a memory card cannot be chosen. If the phone has too little space, the app tells you. If you cancel saving, the files already saved stay.

Can I pause a scan and continue it later?

  • Yes. Pause stops reading for now.
  • Stop scan asks Stop the scan? The files found so far are kept, and the scan is saved so you can resume it later. Tap Keep scanning to go on instead.
  • Next time you open the tool with the same drive, Last scan of this drive offers Open, Continue scan and Delete.
  • If you leave the app, the scan is paused until the app is in front again. Without Pro, it is also paused while the phone is offline or an ad blocker is active.
  • If the drive is unplugged, the scan pauses; it is never cancelled. Plug the same drive in again, in any port, and the scan continues. Another drive is never read in its place.

How many tokens does recovery use?

None. Scanning and recovering files is free.
