How do I back up a drive?

  1. Connect the drive to your phone with a USB OTG adapter and open Ultimate USB or USB Tools.
  2. Open the Disk Management group and tap Backup / Restore.
  3. Tap Backup and pick the folder where the backup goes.
  4. The whole drive is saved as one file named ultimate_backup_ plus a number, with the extension .bk.

The backup file is as large as the whole drive. If the folder has too little space, the app shows Not Enough Space. If the folder cannot be opened, it shows Error opening output directory. A file over 4 GB cannot be saved to a FAT32 drive, and the app tells you so.

How do I restore a backup?

  1. Connect the drive and open Backup / Restore.
  2. Tap Restore and pick the .bk file.
  3. The app shows All Data Will Be Permanently Deleted. Confirm, and the file is written to the drive.

The drive must be at least as big as the backup file.

To look inside a .bk file without restoring it, open it in Ultimate USB's Partition Image Manager. To back up one partition instead of the whole drive, use Backup in Partition Wizard.

How many tokens does a backup or restore use?

None. Backup and Restore are free.

What if I stop it or unplug the drive?

  • To stop, tap cancel and confirm Are you sure you want to cancel the process?
  • A cancelled backup deletes its unfinished file.
  • A cancelled restore leaves the drive only partly written.
  • If the drive is unplugged or stops answering, the app shows Device Removed with Retry. Plug the same drive back in and tap Retry: the backup or restore continues from where it stopped. A different drive is never written.
