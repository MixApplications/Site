Steps

  1. Connect the drive to your phone with a USB OTG adapter and open Ultimate USB.
  2. Open the File & Storage group and tap USB File Manager.
  3. The app shows Waiting For USB Device… and then Reading USB Device…. If it finds no partition, it shows No Partitions Found!
  4. Tap a partition in the grid. To rename it, long-press it and tap Rename.
  5. Browse the folders. The path at the top shows where you are.

How do I copy many files at once?

  1. Select the files. The selection bar shows Clear Selection, Select All, Cut, Copy and Delete.
  2. Tap Select All to select everything in the folder, then Copy or Cut.
  3. Go to the target folder and tap Paste in the toolbar.

To copy files out of the drive, select them and use Export in the selection menu. FAT32 cannot hold files of 4 GB or more, and the app tells you when a file hits this limit.

How do I add files from my phone to the drive?

Open the folder on the drive, tap More in the toolbar and choose Import File / Files or Import Directory. Create Directory in the same menu makes a new folder.

What can I do with selected files?

ActionWhat it does
Cut, CopyMoves or copies the files when you tap Paste in another folder.
DeleteDeletes the files after you confirm.
RenameRenames one selected item.
ExportCopies the selected files out of the drive.
PropertiesShows the details of one selected item.
Open for editingOpens the file in another app that may also save changes to it.

How do I find and sort files?

Tap Search in the toolbar (Search files). Tap Sort By to sort by Name (A–Z or Z–A), Size (smallest or largest first) or Date (oldest or newest first).

Can I open a file in another app without copying it?

Yes. Tap a file and choose the app. The file opens read-only, straight from the drive. Use Open for editing when the other app should be able to save changes. Some files open as a copy instead. APK files cannot be opened.

Which file systems does it open?

FAT12, FAT16, FAT32, exFAT, NTFS, ext2, ext3 and ext4. A drive opens here even when the phone's own file manager does not show it.

The drive opens read-only when it is write-protected, or when a repair it needs did not succeed.

Does the file manager use tokens?

No. USB File Manager is free.

To let other apps reach a whole partition through Android's file picker, use Partition Mounter.
