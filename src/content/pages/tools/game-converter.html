Steps

  1. Open Ultimate USB or USB Tools.
  2. Open the Gaming Tools group and tap Game Converter.
  3. Source Format: choose the format of your game image. ISO is selected first.
  4. Destination Format: choose the format you want.
  5. Under File Selection, tap Pick File and then Pick output directory. Each shows Not Selected until you choose.
  6. If Gap Adjustment appears, keep None or choose Gap +2s or Gap -2s.
  7. Tap Convert.

If the output file already exists, the app shows Files already exist. Tap Replace or Keep both.

Which formats can I convert, and to what?

Every source format converts to every destination format except itself. GDI (Dreamcast) converts to CHD only.

For BIN/CUE and ECM, the app asks whether you select a file or Select a Directory (BIN + CUE / ECM + CUE). If a folder holds several games, the app offers All games (N) first, so you can convert them all at once.

Is the conversion done in one step?

These pairs convert in one step: BIN/CUE to ISO, VCD or CHD; ISO to ZSO, CSO, CHD, VCD or BIN/CUE; VCD to ISO or BIN/CUE; ZSO to ISO or CSO; CSO to ISO or ZSO; CHD to ISO or BIN/CUE.

The other pairs take more than one step.

What is Gap Adjustment?

Gap Adjustment appears only when you convert one BIN/CUE game with several tracks to VCD. The values are None (the default), Gap +2s and Gap -2s.

Does Game Converter use tokens?

No. Game Converter is free.

To put a converted PS2 game on a USB drive for OPL, use PS2 USB Utils. It imports ISO and ZSO games and PS1 .VCD games.
