How do I change partitions step by step?

  1. Connect the drive to your phone with a USB OTG adapter and open Ultimate USB or USB Tools.
  2. Open the Disk Management group and tap Partition Wizard.
  3. Tap a partition, or Unallocated Space, in the list.
  4. Pick an action: Create, Format, Delete, Wipe, Rename, Backup, Restore or Convert. The action is added to the Changes list.
  5. Add more actions if you need them. Undo removes the last planned change.
  6. Tap Apply Changes. The app asks Are you sure you want to apply all changes? This operation cannot be undone. and shows how many tokens the changes use. Confirm to start.

If you leave the screen with planned changes, the app shows Unsaved Changes and asks whether you want to exit without saving.

What does each action do?

ActionWhat it does
CreateMakes a new partition in empty space of at least 32 MB, with FAT16, FAT32, exFAT, NTFS, EXT2, EXT3 or EXT4. It uses all of the space unless you set a custom size.
FormatFormats the partition with the file system, Cluster Size and label you choose.
DeleteRemoves the partition, so its space becomes unallocated.
WipeErases everything on the partition and removes it.
RenameGives the partition a new name.
BackupSaves the partition as an .img file named backup_ plus a number, in a folder you pick.
RestoreWrites an image file back to the partition. The file must be exactly the size of the partition.
ConvertConverts the partition table from MBR to GPT or from GPT to MBR.

Each action changes only the partition you picked.

Which limits does the wizard check?

The wizard stops a change that the drive cannot hold, and tells you why:

  • A new partition needs at least 32 MB of empty space.
  • An MBR drive holds at most 4 partitions. A GPT drive with more than 4 partitions cannot be converted to MBR.
  • FAT32 cannot handle partitions larger than 2TB and MBR cannot handle partitions larger than 2TB. Use exFAT or NTFS, or GPT, for a larger partition.
  • A partition that reaches past the drive's real size is marked in the list.
  • If a conversion from MBR to GPT is refused, the app explains why.
  • On a write-protected drive, only Backup runs.

Back up the drive first with Backup / Restore: a change to a partition table is not one you want to stop halfway through.

Is Partition Wizard safe for my drive?

Yes. The app tests every new or formatted partition before it reports success, and it protects the drive at each step:

  • Create and Format check and test the new file system before the app reports success.
  • If the drive did not keep its test data, it may be fake. The app says so, keeps its files read-only and offers Try restore again.
  • If you kept the claimed size of a drive that may be fake, the app warns you once before it writes, with Continue and Cancel. If you cancel, nothing is written and no token is used.
  • A job never writes to a different drive than the one it started on.
  • If the USB connection fails for a moment during a job, the app recovers it automatically and the job continues.

How many tokens does Partition Wizard use?

Apply Changes uses 1 token for each Create or Format in the list, and at most 3 tokens in total. Convert, Delete, Wipe, Rename, Backup and Restore are free. The app shows the cost before it starts, and you earn a token by watching one short rewarded video. With Pro, Partition Wizard uses no tokens.

If the changes fail, the tokens for the Create and Format steps that did not finish come back. If the app is closed while the changes run, the tokens are returned the next time the app starts.

Can I stop the changes while they run?

Yes. Tap cancel and the app asks Are you sure you want to cancel the process? If the drive is unplugged while the changes run, the app reports Device Removed.
